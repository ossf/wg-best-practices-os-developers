Evaluate merge/pull requests

In all cases, whether code changes were created by AI or by humans, look for vulnerabilities in each merge/pull request.

  • Have AI and a human review the proposed change before it’s even submitted
  • “Enforce automated security assessments consistently in your development processes, including using LLM-powered agents to find vulnerabilities before attackers do” [CSA2026]
  • “All code (human or AI-generated) should pass LLM-driven security review before merge.” [CSA2026]
